# Security

Lexicast delivers texts that appear inside other people's applications, so a flaw here can reach many users. Please report vulnerabilities privately and do not open a public issue.

- Use GitHub's "Report a vulnerability" (private security advisory) on this repository.
- Please include the version, steps to reproduce and the impact.

Design rules the project holds itself to: translations are plain text only, releases are reviewed by a second person and signed, there are no default credentials, and delivery paths accept a fixed allow-list only.
